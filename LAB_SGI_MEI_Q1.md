## Unity + Meta Quest 3 + OpenXR Project SGI-MIRI Q1. 2025-2026

Este Proyecto se realizará en grupos de 2 personas, y se debe entregar vía el Racó el día 4 de noviembre de 2025. El proyecto se presentará al profesor durante el horario de clases de SGI el día 5 de noviembre de 2025.

## Descripción del Proyecto:

El objetivo de este Proyecto es que aprendáis a diseñar una aplicación de Realidad Virtual para el Meta Quest 3 utilizando Unity y OpenXR. Podéis encontrar toda la información y los links necesarios para este proyecto, en los apuntes que tenéis en el Racó.

La aplicación debería incluir lo siguiente:

- Un pequeño entorno de realidad virtual con varios objetos con los que se pueda interactuar.

- Navegación: Se puede usar cualquiera de las metáforas que hemos visto en las clases de teoría para mover la cámara por el entorno virtual (movimiento constante, selección de ruta sobre plano, teletransporte, etc.). Algunos métodos ya están listos para usarse en OpenXR y los paquetes de Meta que instaléis, así que es importante que intentéis implementar nuevas funcionalidades que no estén de por sí incluidas en las demos. Se recomienda entonces tener varias opciones de navegación (2+) así como opciones de configuración para el usuario.

- Selección: El usuario debe tener algún modo para poder seleccionar objetos de la escena, así como poder realizar acciones con ellos, como aplicarles transformaciones geométricas para realizar tareas de manipulación (rotación, traslación, escalado).

- Control: Ofrecer al usuario la posibilidad de hacer alguna tarea de control, vía 3d GUIs si es necesario, por ejemplo: modificar el color de algún objeto, cargar un modelo en la escena, cambiar entre métodos de interacción, cambiar el estado de la aplicación, etc.

El tema del Proyecto es libre, podéis implementar la aplicación que queráis. Por ejemplo: un museo virtual, un escenario de una ciudad por al que se pueda navegar, una tienda virtual, un juego, etc. … Lo que se valorará del proyecto será que la selección de metáforas para navegación, selección, y manipulación sea consistente con el objetivo de vuestra aplicación, así como el diseño e implementación de la interfaz de control. Se valorará la facilidad de uso de los elementos de interacción, así como el correcto uso de feedback. No es necesario que modeléis vosotros mismos los objetos de la escena, hay muchos modelos disponibles y gratuitos en el Unity Asset Store.


## Entrega (4 de noviembre 2025):

Tenéis que entregar todos los ficheros necesarios para compilar y ejecutar vuestro Proyecto, junto con un documento que explique brevemente el objetivo de la aplicación y un manual de uso de los elementos de interacción 3D. En este documento también es muy recomendable añadir una “disclosure notice”, en la que

se lista el uso de las herramientas foráneas (Tutoriales de proyectos, LLMs…) dado que un

uso no declarado de estas herramientas se puede interpretar como copia.

Entregar también un video mostrando el funcionamiento de vuestra aplicación. Las carpetas

necesarias para ello suelen ser únicamente: Assets, Packages, ProjectSettings y UserSettings.
